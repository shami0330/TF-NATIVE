# TootFarangi (توت فرنگی) — نسخهٔ نیتیو مک

این پوشه یک پروژهٔ کامل است. با آپلود آن در گیت‌هاب، خود گیت‌هاب برنامه را می‌سازد و فایل نصبی (`.dmg`) می‌دهد.

## ۱) آپلود در گیت‌هاب
1. در github.com وارد شو و یک مخزن (Repository) جدید بساز؛ نامش `TootFarangi` باشد (خصوصی یا عمومی، فرقی ندارد).
2. در صفحهٔ مخزن: **Add file ← Upload files**.
3. **همهٔ** محتویات همین پوشه را بکش و رها کن، از جمله پوشهٔ مخفی `.github`.
   - در Finder برای دیدن فایل‌های مخفی: **Command + Shift + .** (نقطه) را بزن.
   - اگر `.github` آپلود نشد: **Add file ← Create new file**، در خانهٔ نام بنویس `.github/workflows/build.yml` و محتوای فایل `build.yml` را داخلش بچسبان.
4. پایین صفحه **Commit changes** را بزن.

## ۲) ساخت برنامه
1. بالای مخزن روی تب **Actions** برو. کار «Build macOS app» خودش شروع می‌شود (حدود ۵ تا ۱۰ دقیقه). اگر شروع نشد: روی آن کلیک کن ← **Run workflow**.
2. وقتی تیک سبز شد، روی همان اجرا کلیک کن؛ پایین صفحه در بخش **Artifacts** فایل `TootFarangi-mac` را دانلود کن.
3. داخل آن دو فایل است: `TootFarangi-arm64.dmg` (برای مک‌های M1/M2/M3 — این را بردار) و `TootFarangi-x64.dmg` (مک‌های اینتل).

## ۳) نصب
1. فایل dmg را باز کن و TootFarangi را بکش داخل Applications.
2. بار اول: روی برنامه **راست‌کلیک ← Open** و دوباره Open را بزن (چون برنامه از اپ‌استور نیست).
3. اگر نوشت «damaged / خراب است»، در Terminal این را بزن و Enter:
   `xattr -cr /Applications/TootFarangi.app`
4. بار اول که پوشهٔ ذخیره‌سازی خواست، **همان پوشهٔ قبلی (مثلاً «کلاس من»)** را انتخاب کن تا همهٔ اطلاعاتت برگردد.

## ۴) ضبط تخته (ضبط صفحه و میکروفون)
- اولین بار مک اجازه می‌خواهد. اگر نخواست یا ضبط نشد: **System Settings ← Privacy & Security ← Screen & System Audio Recording** (و **Microphone**) ← TootFarangi را روشن کن، بعد برنامه را کامل ببند (Command+Q) و دوباره باز کن.
- برنامه خودش فقط پنجرهٔ TootFarangi را ضبط می‌کند (بدون پنجرهٔ انتخاب).
- ضبط «صدای سیستم» در مک پشتیبانی نمی‌شود؛ میکروفون کار می‌کند.
- هر بار که برنامه را دوباره بسازی و نصب کنی، ممکن است مک مجوزها را از نو بخواهد.

## ۵) به‌روزرسانی بدون اینترنت
داخل برنامه: تنظیمات ← ذخیره‌سازی ← «به‌روزرسانی کامل برنامه (بدون اینترنت)» ← **انتخاب فایل HTML** ← **اعمال به‌روزرسانی**. برنامه خودش نسخهٔ قبلی را نگه می‌دارد، فایل را عوض می‌کند و دوباره باز می‌شود. «بازگشت به نسخهٔ قبلی» هم همان‌جاست.
اگر بعداً فایل dmg جدیدتری نصب کنی، نسخهٔ داخل dmg اگر جدیدتر باشد خودکار اولویت دارد.

## ۶) عوض کردن خود برنامه در مخزن
فایل `app/index.html` همان برنامه است. برای نسخهٔ جدید، همین فایل را (با همین نام `index.html`) در مخزن جایگزین کن؛ گیت‌هاب دوباره می‌سازد.

## ۷) اگر مشکلی بود
فایل لاگ اینجاست (منوی Help ← Open log folder هم باز می‌کند):
`~/Library/Application Support/TootFarangi/crash.log`
متن آخر این فایل را برای من بفرست. برای دیدن خطاها: منوی View ← Toggle Developer Tools (Option+Command+I) ← Console.

## Appwrite (اتصال به سرور)
- یک بار در Appwrite Console ← پروژه ← Overview ← Add platform ← Web ← Hostname: `localhost`
  (اگر دامنهٔ github.io خودت را ثبت کرده‌ای، همان را در `appwrite.json` بنویس: `{ "origin": "https://نام.github.io" }`).
- منوی Help ← **Appwrite: test connection** دلیل دقیق مشکل را نشان می‌دهد.
- اگر با این‌ها هم وصل نشد: در `appwrite.json` مقدار `relaxWebSecurity` را `true` کن و برنامه را دوباره باز کن.
- فایل SDK بعد از اولین اجرای آنلاین ذخیره می‌شود تا بدون اینترنت هم لود شود.
